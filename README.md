# ⭐ Featured Project

## 🧴 Lumina Skin — Full-Stack AI-Powered Application

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge\&logo=github)](https://github.com/GabrielJalmeida/api-analise-pele)

A full-stack application that started as a skincare analysis API and evolved into a complete system with a public frontend, administrative dashboard, product catalog, recommendation engine and AI integration.

The project was designed around an important architectural principle:

> **AI interprets. The API decides.**

Generative AI is used to transform unstructured information such as images and text into structured data, while deterministic backend rules remain responsible for product recommendations and business logic.

### What I built

* REST API with **Python and FastAPI**
* AI integration supporting multiple providers
* Deterministic recommendation engine
* Product catalog and inventory management
* SQLite database
* Image processing
* CSV/XLSX catalog import
* Public web application
* Administrative dashboard
* Automated backend tests
* GitHub Actions CI workflow
* API documentation with Swagger

### Stack

`Python` · `FastAPI` · `Pydantic` · `SQLite` · `React` · `TypeScript` · `Vite` · `Tailwind CSS` · `Ant Design` · `Pytest` · `GitHub Actions` · `AI APIs`

# 💡 How I Approach Development

```text
Understand the problem
        ↓
Break it into smaller problems
        ↓
Research what I don't know
        ↓
Choose the right tools
        ↓
Build
        ↓
Test
        ↓
Improve
```

I value **learning ability over memorizing tools**.

If a project requires something I haven't used before, my first reaction isn't *"I don't know how to do that."*

It's:

**"What do I need to learn to make this work?"**
