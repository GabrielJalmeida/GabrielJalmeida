## About

I'm studying **Systems Analysis and Development at FATEC** and building toward a career in software development with a backend-first mindset. I enjoy connecting application logic, APIs and relational databases to make everyday processes clearer, more reliable and less repetitive.

My main interests are **backend development, API design, business software and automation**. I also explore frontend work, data analysis and application security to understand more of the system end to end.

I care about explicit business rules, predictable behavior and tests that make important decisions easier to verify. For AI-enabled projects, one principle guides my choices: **AI can help interpret information; critical business decisions should remain in validated application logic.**

## Selected work

### [Lumina Skin](https://github.com/GabrielJalmeida/api-analise-pele)

A full-stack skincare analysis and product-recommendation platform. AI helps structure information from text or images, while deterministic backend rules handle product compatibility and business decisions.

**Stack:** Python · FastAPI · Pydantic · SQLite · React · TypeScript · Pytest

### [LeadFlow Agent](https://github.com/GabrielJalmeida/leadflow)

A local-first lead research and sales workflow that investigates businesses, evaluates evidence and organizes qualification and follow-up. It is designed to preserve uncertainty rather than attach information to the wrong business.

**Stack:** Python · FastAPI · React · AI provider integrations  
**Status:** Alpha

### [Estoque Flex](https://github.com/GabrielJalmeida/baby-belo)

A multi-company inventory system built around traceable stock movements, configurable item fields and role-aware access. The backend uses a modular structure to keep inventory rules, customization and authorization responsibilities distinct.

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · React · Pytest

## Security lab

### [Cyber Lab — Vulnerable Login Lab](https://github.com/GabrielJalmeida/cyber.vulnerable-login-lab)

An educational lab for studying web authentication behavior and authorized FTP/SMB service auditing inside an isolated virtual network. The repository documents the intentionally vulnerable baseline and the evidence collected during controlled exercises.

> [!CAUTION]
> This project is intentionally vulnerable and is for education in isolated, authorized environments only. The defensive counterpart is not implemented yet; its starter structure must not be treated as secure software.

The goal is to bring application-security thinking into the systems I build — not to present an unfinished lab as a production security tool.
